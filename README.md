# SALR
SALR: Sharpness-aware Learning Rate Scheduler for Improved Generalization

A learning-rate scheduler that raises the step size where the loss is sharp, helping optimizers escape sharp minima and settle in flatter ones that generalize better. The code for the CIFAR-10, CIFAR-100 and ImageNet experiments is in the three zip files.
